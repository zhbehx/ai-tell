# 案例：85 分 → 0 分，同一篇内容

同一件事（小红书爆款没转化），两种写法。分数由 `scripts/ai_tell.py` 实测。

## 原文（AI 味 85.1）

```
在当今社交媒体快速发展的时代，小红书已经成为品牌营销的重要阵地。如何打造爆款笔记，是每个运营者都需要深入思考的核心问题。

首先，内容是王道。优质的内容不仅能够吸引用户的注意力，而且能够建立品牌的长期价值。我们需要从用户需求出发，持续输出有价值的内容。

其次，互动至关重要。私信回复的及时性和专业性，直接影响到用户的转化效率。值得注意的是，很多运营者忽视了主页简介的优化，这其实是一个关键的抓手。

最后，数据是最好的老师。通过全链路的数据分析，我们能够不断优化运营策略，实现降本增效，构建完整的增长闭环。

综上所述，打造爆款笔记需要内容、互动、数据三位一体的方法论。希望这些内容对你有所帮助，让我们一起在小红书的赛道上持续深耕，共创未来。
```

## 改写（AI 味 0.0）

```
那条笔记爆的时候，我在外面吃饭。点赞从 200 涨到 1.2 万，我盯着手机看了四十分钟，筷子都没动。

当晚私信 300 多条。我一条条回，回到凌晨 2 点。

第二天早上我数了一下，真正加上微信的是 11 个。

1.2 万点赞，11 个人。我以为是回复话术的问题，改了三天话术，第二周又爆了一条，加了 9 个。

问题不在话术。

我把那两条笔记的用户路径走了一遍：笔记讲的是租房收纳，我的主页简介写的是「分享生活日常」。点进来的人看不到下一步该做什么，就走了。

简介改成一句话：租房收纳，每周三更，评论区问尺寸。

第三周再来一条同量级的，加了 62 个。

这件事我记了很久。我们总以为转化靠最后一句话，其实靠的是前面所有页面的路是不是通的。话术只是最后一步，走到最后一步的人本来就没几个。
```

```
$ python scripts/ai_tell.py after.md

AI 味：0.0 / 100    很有人味：细节密度和节奏都自然
字数：264 个汉字   模式：article
```

## 改了什么（逐条对应）

| 动作 | 原文 | 改写后 |
| --- | --- | --- |
| **删** 开场套话 | 「在当今社交媒体快速发展的时代……重要阵地」 | 直接进场景：「那条笔记爆的时候，我在外面吃饭」 |
| **删** 收尾空转 | 「希望这些内容对你有所帮助，让我们一起……」 | 停在结论上，不打招呼 |
| **删** 三段式 | 首先/其次/最后 | 按时间顺序讲一件事 |
| **换** 黑话 | 「关键的抓手」「全链路」「增长闭环」 | 换成「主页简介」「用户路径」「加了 62 个」 |
| **减** 对称句 | 「不仅能够吸引注意力，而且能够建立长期价值」 | 只留能验证的那一半 |
| **添** 具体物 | 无 | 1.2 万、11 个、凌晨 2 点、62 个、第三周 |
| **破** 节拍器 | 每句 20–25 字 | 「问题不在话术。」（6 字） |
| **留** 不完美 | 无 | 「我以为是回复话术的问题，改了三天话术……」——先承认判断错了 |

## 一个反直觉的发现

原文的字数是 284，改写后是 264——**信息量涨了 10 倍，字数反而少了**。

这就是 AI 味的本质：它不是「写得太长」，是**用同样的字数说了更少的事**。

## 你可以这样用它

```bash
# 测自己的稿子
python scripts/ai_tell.py 我的稿子.md --explain

# 卡住不让发：超过 60 分就报错
python scripts/ai_tell.py 我的稿子.md --fail-over 60

# 批量测一个目录
for f in drafts/*.md; do echo "== $f"; python scripts/ai_tell.py "$f" | head -1; done

# 测技术文档（不计结构模板）
python scripts/ai_tell.py README.md --mode doc
```
