# AI 腔模式库

> 每一项都是「AI 会这样写 → 人会这样写」。检测脚本 `scripts/ai_tell.py` 的六个维度，就是按这份清单实现的。

## 一、套话与黑话（权重最高，24%）

AI 最喜欢用抽象名词制造专业感。人不会把「赋能」说出口，只会说「我帮他做了个表」。

| AI 写法 | 人话 |
| --- | --- |
| 为业务赋能 | 帮他省了两天 |
| 形成业务闭环 | 客户投诉有人接了，一周内回访完 |
| 这是关键抓手 | 先改这一个地方 |
| 提升颗粒度 | 从按月改成按天 |
| 底层逻辑是什么 | 为什么会这样 |
| 认知升级 | 我原来想错了 |
| 沉淀方法论 | 我总结了一套做法 |
| 全链路优化 | 从下单到发货每一步都改 |
| 降本增效 | 省了 3 个人力，多做了 40% 的量 |
| 对齐、拉通 | 开会定下来，谁做什么 |

**用 1 个黑话，读者就觉得你在糊弄；用 3 个，读者会直接划走。**

## 二、空转收尾与开场（22%）

这类句子删掉之后，文章一个字的信息都不会少——这就是判断标准。

**开头型（AI 最爱的三件套）**
- 「在当今这个快速变化的时代……」
- 「随着科技的发展，AI 已经深入到我们生活的方方面面。」
- 「众所周知，XX 是一个重要的话题。」

→ 换成：一个具体场景、一个数字、一句冲突。

**收尾型**
- 「希望这些内容对你有所帮助。」
- 「让我们一起拥抱变化，共同成长。」
- 「总而言之 / 综上所述 / 总的来说……」
- 「以上就是全部内容，感谢阅读。」

→ 换成：一个动作指令、一个提问、一句没说完的话。

**过渡型**
- 「值得一提的是」「不难发现」「由此可见」「更重要的是」
- 这些词删掉，句子照样通顺，说明它们本来就没有信息。

## 三、对称句式（16%）

AI 受过大量对仗文本训练，天然爱排比。人说话是不整齐的。

| AI 句式 | 问题 | 改法 |
| --- | --- | --- |
| 不是 A，而是 B | 一句话里塞两个判断，读者记不住 | 只说 B，A 留在心里 |
| 不仅 A，而且 B | 两个「优点」并列，等于哪个都不突出 | 留最硬的一个，配一个数字 |
| 既 A 又 B | 同上 | 选一个说透 |
| 一方面…另一方面… | 假装全面，其实没有立场 | 给结论，说取舍 |
| 首先…其次…最后… | 三段式骨架，AI 最典型指纹 | 按重要性排，别按序数排 |
| 与其 A 不如 B | 只在真做过对比时用 | 加代价：「A 便宜 3 千，但慢两周」 |

**例外**：真做对比时，对称句是有力的。区别在于——人写的对称句后面一定跟着代价或数字。

## 四、结构模板（14%）

标题就是「前言 / 背景 / 现状 / 解决方案 / 总结」这一套，是 AI 的骨架级指纹。

- 「一、二、三、四」的序号小标题 + 每节字数相等 → 一眼 AI。
- 每一段都是「观点句 + 解释句 + 举例句」三连 → 节奏像机器。
- 全文 80% 是列表项、没有一个完整段落 → 像说明书，不像人说话。

**改法**：让段落长短不一。重要的地方写 5 行，不重要的地方一句带过。

## 五、抽象大词（14%）

| AI | 人 |
| --- | --- |
| 具有重要的意义 | 值 40 万 |
| 产生深远影响 | 三个月后我换了工作 |
| 是核心要素 | 没有它就跑不起来 |
| 极大提升效率 | 从 4 小时到 40 分钟 |
| 充分发挥优势 | 把最贵的那个功能砍了 |

**规律**：抽象大词的作用是「避免说具体」，而具体才是可信度的来源。

## 六、句长均匀（10%）

人写字，句长起伏很大。AI 倾向于每句 18–26 字，像节拍器。

- 人：`短句。短句。然后突然来一个很长很长的句子，把所有条件、代价、例外都塞进去，读到一半会想换气。然后再短一句。`
- AI：`每个句子长度都差不多。读起来很顺畅。但读完之后什么都记不住。`

**改法**：故意写一句 4 个字的。故意写一句 60 字的。

## 七、具体性缺失（14%）

人写的东西里有：日期、金额、型号、人名、「他原话是这么说的」。
AI 写的里有：形容词、副词、以及「显著的提升」。

**最低标准**：每千字至少 6 个具体信号（数字 / 日期 / 英文专名 / 引号原话 / 第 N 次）。

## 附：六个维度与分档

| 总分 | 判断 | 该怎么办 |
| --- | --- | --- |
| 75–100 | 一眼 AI | 别改词，重写结构 |
| 60–74 | 很像 AI | 删空转句 + 加 3 个具体细节 |
| 40–59 | 有点 AI 味 | 换掉黑话，加一段真实经历 |
| 20–39 | 基本像人 | 只改个别句子 |
| 0–19 | 很有人味 | 可以发 |

## 一句提醒

**检测器测的是「文本特征」，不是「作者身份」。** 人也能写出 70 分的稿子（尤其是照着模板写的），AI 也能写出 10 分的稿子（尤其是被要求「说人话」且给了素材的）。

它的用途是：**在你发出去之前，告诉你哪几句最像敷衍。**
